# What is ***Staging*** in GIT?

1. Staging in Git is the process of adding selected changes to the staging area so they can be included in the next commit.
   
   ---
2. ###### Staging in Git is the process of selecting and preparing changes to be included in the next commit.



###### **Here is the process of the** 



##### Working Directory → Staging Area → Commit





1. ##### Stage Command 

*  	git add .           (Staging all files with the name)
* &nbsp;	git add ***file.txt***    (Staging a specific file with the name)
* &nbsp;	git add -p 	    (Stagging part of the file)







##### &nbsp;	git status 		( To Check the status of the repository)



---

##### 2\.  Unstage File 

&nbsp;	git restore --staged *file.txt  (unstage the file)*
